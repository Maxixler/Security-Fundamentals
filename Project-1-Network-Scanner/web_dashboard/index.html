Learn

Network security concepts and terminology

OSI Model

The 7-layer model that explains how network communication works. From physical cables (Layer 1) to applications (Layer 7). Understanding this is fundamental to network security.

7. Application 6. Presentation 5. Session 4. Transport 3. Network 2. Data Link 1. Physical

TCP 3-Way Handshake

How TCP connections are established between two hosts. This is the foundation of port scanning.

→ SYN Client initiates
← SYN-ACK Server acknowledges
→ ACK Connection established

Port States

What different scan results mean from a security perspective.

OPEN Service is listening - potential attack surface
CLOSED No service listening - host is alive
FILTERED Firewall blocking - can't determine state

Common Security Risks

Ports and services that frequently pose security risks in enterprise networks.

Port 23 (Telnet) - Unencrypted remote access
Port 445 (SMB) - Ransomware vector (WannaCry)
Port 502 (Modbus) - No authentication (OT/ICS)
Port 3389 (RDP) - Brute force target
Port 161 (SNMP) - Information leak
